# Nhật ký học PySpark theo từng buổi

Mỗi chapter/bài học sẽ có một file riêng để ghi lại:

- Mục tiêu buổi học
- Câu hỏi / vấn đề cần giải quyết
- Công việc đã làm
- Kết quả
- Vấn đề còn lại
- Bước tiếp theo

## Cấu trúc khuyến nghị

```text
docs/logs/
├── README.md
├── chapter-00-template.md
├── chapter-00b-template.md
├── chapter-00c-template.md
└── ...
```

## Template dùng cho từng chapter/bài

Mỗi file nên chứa các phần sau:

1. Tên chapter/bài
2. Mục tiêu
3. Bối cảnh dữ liệu / khái niệm liên quan
4. Phương pháp / kỹ thuật áp dụng
5. Code đã viết
6. Kết quả chạy thử
7. Lỗi gặp phải và cách xử lý
8. Kết luận / ghi chú
9. Plan cho buổi sau

---

Hướng dẫn:
- Không cần ghi quá nhiều nội dung dài dòng
- Ghi theo kiểu "hôm nay làm gì" để dễ review sau này
- Dùng tiếng Việt để đồng bộ với tư duy học tập
